# 更新记录

## v0.11.3

- 新增 **OPPO Pad 4 Pro（3392×2400）** 版式。平板与手机界面结构完全不同：商店在屏幕底部、卡名条在卡片下沿、金币在顶部中央偏右、刷新按钮在左下角；识别流程本身无需分支，差异全部由 `PhoneLayout.Spec` 描述。
- `Spec` 增加 `costDy`（费用框相对卡名框顶的纵向偏移）：手机为 0，平板为 5（费用图标略高于卡名文字顶）。
- 平板实测：卡位间距 490（手机 430~457）、卡名框左沿 761/1251/1741/2232/2722、卡名框顶 2287、费用偏移 371、金币框 1645,1828（173×77，需包住「🪙50」整体）、刷新框 290,2210、点击点取立绘区中心（偏移 182、Y 2065）。
- 新增 `assets/templates-pad/` 字模：5 个卡名（艾尼维亚/崔丝塔娜/科加斯/提莫/米利欧）、1/2/3 费与刷新模板，均由原生截图生成。
- 端到端离线验证：商店门禁 1.000、卡名 5/5 命中、费用 5/5 正确。

## v0.11.2

- 商店识别改为**按机型查表**：`PhoneLayout` 现在由截图的 `宽×高` 选版式，新增 K80 至尊版（**2772×1280**）。小米 14 的坐标、尺寸和点击点保持原值不变，行为与 v0.11.1 完全一致。
- K80 版式由 2772×1280 截图逐区域实测标定：卡位间距 457（小米 14 为 430，比屏幕缩放比例更宽，不能等比复用），卡名框左沿 446/902/1360/1816/2274、框顶 523，费用框偏移 371，金币框 2533,1094，刷新框 2531,846，点击点取卡面正中（偏移 189、Y 347，实测偏差 ≤2 像素）。
- 每帧截图把自身尺寸写进 `BuyPolicy.Frame`，点击坐标严格取自同一版式，避免识别与点击用错坐标系；帧缓存同时校验分辨率。
- 字模改为**清单驱动、按机型分目录**（`assets/templates/`、`assets/templates-k80/`），每个目录用 `manifest.txt` 声明自己有哪些卡名，因此不同机型可以覆盖不同卡池。K80 目录已用原生 2772×1280 截图生成 5 个卡名（贝蕾亚/嘉文四世/璐璐/娑娜/艾尼维亚）、1 费字模与刷新模板；未覆盖的卡名与费用档跳过字模、交由 OCR 与目录兜底。
- 不再跨机型回退字模：两机字号差 5~7%，小米 14 字模在 K80 上的相似度仅约 0.54，套用会让模板把别的卡认成目标卡。缺专用字模时停用模板快速路径，只走 OCR。
- 阵容导入（`LineupVision` 的标题带、按钮带、行签名）仍只有小米 14 标定，K80 上会明确提示“仅小米 14 2670×1200 已标定，当前机型不可用”，不会误点。
- 不支持的分辨率现在会在状态栏回显实际尺寸（如“已开启 · 1386×640 不在支持范围，等待横屏”），便于真机排查。

## v0.11.1

- 修复点击“显示悬浮窗”时报 `The specified child already has a parent`、悬浮窗完全无法打开的问题。原因是“当前卡组”标签在 v0.11.0 改造为带赛季标签的标题行时，仍保留了一次直接添加到面板的调用，同一 View 被挂了两个父容器。

## v0.11.0

- 新增“棋子赛季”选项，可在 **S18（默认）** 与 **S16（返场）** 之间切换；影响搜索选卡的目录、缺失费用兜底和阵容导入时的头像识别。
- 随包新增 S16 棋子目录（119 个棋子，含返场新增的斯莫德、梅尔、亚恒等）与对应头像，S16 头像放在 `assets/portraits/s16/`，S18 头像迁至 `assets/portraits/s18/`。
- 切换赛季时重建商店识别器并取消进行中的阵容导入；已选名字按原顺序保留，不在新赛季的棋子会提示核对，不会被静默删除。
- 字形模板快速路径只采信当前赛季目录中存在的名字，避免 S18 模板在 S16 下误判。
- 新增 `tools/prepare_catalog.py`：按同一筛选规则抓取指定赛季目录与头像，`--check` 可校验随包数据与接口是否一致。
- 上游数据偶有同名不同费（S16 的波比 2/3 费、伊泽瑞尔 4/5 费），这类名字不参与费用兜底，等待 OCR 实际读数。

## v0.10.0（测试版，第三套导入与预览已实机验证）

- 游戏实测已完成第三套替换和应用；每次导入成功均刷新本地阵容预览，返回助手时重新载入图片。应用后的短暂标题 OCR 波动，可由已核对行的头像图像和“取消”状态共同确认。
- 实机回测：用户确认重新导入后第三套紧凑阵容图已更新，本地预览文件已保存。

- 支持批量阵容码、自动提取名称、复制代码及保留旧手动卡组，上限 200 套。
- 初次未解析阵容在开启拿卡时先导入一次；已解析后不因开启开关反复导入。
- 商店打开时先点总金币收起，再导入剪贴板；收藏满时替换并应用第三套。
- 预览只保留目标行的名称和英雄，排除应用按钮和多余右侧空白，提示遮挡时等待。
- 头像解析与本地缓存；不完整结果需要明确核对确认，导入期间暂停普通买卡/刷新。
- README 顶部增加用途、数据交互和公平竞技免责声明。
